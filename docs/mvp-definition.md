# Minimum Viable Product (MVP)

## Goal

Deliver a production-ready finance management application that provides the core functionality needed for users to manage their personal finances.

---

# Included Features

## Authentication

- Register
- Login
- Logout
- Password Reset (via Security Transactional Email)
- Account Deletion & Data Purging
- Protected Routes

---

## Dashboard

- Financial Summary
- Balance Card (Net Balance supporting positive and negative values)
- Income Card
- Expense Card
- Recent Transactions
- Calendar Month Summary Selector

---

## Transactions

- Add Transaction (Type, Amount, Category, Date, Merchant/Payee, Notes)
- Edit Transaction (Supports Backdating & Dynamic Recalculation)
- Delete Transaction
- Search (Keyword, Merchant, Notes)
- Filter (Type, Category, Date Range)
- Categorize Transactions

---

## Categories

- Default Pre-seeded System Categories
- Create Custom Categories
- Edit Custom Categories
- Delete Custom Categories (with Transaction Reassignment)

---

## Budgets

- Create Monthly Budget per Category
- Edit Budget
- Delete Budget
- Budget Progress Tracking
- Visual Warning Thresholds (Approach Warnings at 80% & Exceeded Warnings at 100%+)

---

## Savings Goals

- Create Savings Goal
- Edit Savings Goal
- Delete Savings Goal
- Track Goal Progress & Record Contributions

---

## User Profile

- Update Profile (Display Name, Email)
- Upload Avatar
- Theme Settings (Light/Dark Mode)
- Currency Symbol Display Settings

---

## Analytics

- Spending by Category
- Monthly Income
- Monthly Expenses

---

# Excluded from MVP

- Marketing & Reminder Email Notifications (Transactional security emails for Password Reset are Included)
- Multi-currency Exchange Rate Conversion (Currency Display Symbol preferences are Included)
- AI Financial Assistant
- Bank Account Integration
- Receipt Scanning
- Mobile Application
- Multi-user Budget Sharing
- Investment Tracking
- Cryptocurrency Support
- Subscription Tracking
- Export to PDF
