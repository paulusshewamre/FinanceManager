# Use Cases

## UC-001 Register

Actor:
Guest

Goal:
Create a new account.

Success Outcome:
User account is created.

---

## UC-002 Login

Actor:
Registered User

Goal:
Access personal dashboard.

Success Outcome:
User is authenticated.

---

## UC-003 Add Transaction

Actor:
Authenticated User

Goal:
Record a financial transaction.

Success Outcome:
Transaction is saved.

---

## UC-004 Edit Transaction

Actor:
Authenticated User

Goal:
Update transaction information.

Success Outcome:
Transaction is updated.

---

## UC-005 Delete Transaction

Actor:
Authenticated User

Goal:
Remove an unwanted transaction.

Success Outcome:
Transaction is deleted.

---

## UC-006 Create Budget

Actor:
Authenticated User

Goal:
Set monthly spending limits.

Success Outcome:
Budget is created.

---

## UC-007 View Dashboard

Actor:
Authenticated User

Goal:
View financial overview.

Success Outcome:
Dashboard displays updated information.

---

## UC-008 Create Savings Goal

Actor:
Authenticated User

Goal:
Create a savings target.

Success Outcome:
Goal is saved.

---

## UC-009 Update Profile

Actor:
Authenticated User

Goal:
Modify account settings.

Success Outcome:
Profile is updated.

---

## UC-010 Logout

Actor:
Authenticated User

Goal:
End current session.

Success Outcome:
User is logged out securely.

---

## UC-011 Reset Password

Actor:
Guest / Registered User

Goal:
Reset forgotten account password via email recovery token.

Success Outcome:
Password is reset and user can log in with new credentials.

---

## UC-012 Manage Categories

Actor:
Authenticated User

Goal:
Create, edit, or delete custom categories (and reassign transactions when deleting a category).

Success Outcome:
Category structure and assigned transactions are updated.

---

## UC-013 Update Savings Goal Progress

Actor:
Authenticated User

Goal:
Edit savings goal parameters or record contributions toward a savings target.

Success Outcome:
Goal details and progress percentage are updated.

---

## UC-014 Delete Account

Actor:
Authenticated User

Goal:
Permanently delete user account and purge all personal financial records.

Success Outcome:
User account and associated data are permanently purged from the system.
