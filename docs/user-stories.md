# User Stories

## Authentication

As a new user,
I want to create an account,
so that my financial information is securely stored.

---

As a returning user,
I want to log in,
so that I can access my dashboard.

---

As a user,
I want to reset my password via transactional email,
so that I can recover my account securely.

---

As a user,
I want to permanently delete my account,
so that my personal financial data is erased completely.

---

## Dashboard

As a user,
I want to immediately see my financial summary and net balance,
so that I understand my current financial situation.

---

As a user,
I want to view recent transactions,
so that I can monitor my latest activity.

---

## Transactions

As a user,
I want to add income,
so that I can keep track of my earnings.

---

As a user,
I want to add expenses,
so that I know where my money is going.

---

As a user,
I want to record the transaction date and merchant/payee name,
so that I can accurately track when and where money was spent.

---

As a user,
I want to edit transactions,
so that I can correct mistakes and update historical records dynamically.

---

As a user,
I want to delete transactions,
so that I can remove incorrect records.

---

As a user,
I want to search transactions by keyword or merchant,
so that I can quickly find previous records.

---

As a user,
I want to filter transactions,
so that I can analyze my spending habits.

---

## Categories

As a new user,
I want to have pre-seeded default categories available,
so that I can immediately start logging transactions without manual setup.

---

As a user,
I want to organize transactions into custom categories,
so that I understand my spending habits.

---

As a user,
I want to reassign transactions when deleting a custom category,
so that my financial records remain properly categorized.

---

## Budgets

As a user,
I want to create monthly budgets per category,
so that I stay within my spending limits for each calendar month.

---

As a user,
I want to receive visual warnings when approaching my budget limit (e.g., at 80%) and when I exceed my budget,
so that I can manage my spending proactively.

---

## Savings Goals

As a user,
I want to create savings goals,
so that I stay motivated to save money.

---

As a user,
I want to edit or delete savings goals and record progress contributions,
so that my goals accurately reflect my current savings targets and progress.

---

As a user,
I want to monitor my savings progress percentage and status,
so that I know how close I am to achieving my goal.

---

## Profile

As a user,
I want to customize my profile preferences and display currency symbol,
so that the application matches my local format and visual needs.
